# PackGuard

PackGuard is a client-side Fabric and Forge mod for Minecraft Java Edition. It blocks the built-in TrueType font loader and checks server resource pack ZIPs before the game applies them. On Windows, it also restricts direct child processes.

Put the JAR in your Minecraft instance's `mods` folder. Blocked resources are recorded in `logs/packguard-blocks.tsv`.

Supports Minecraft Java Edition 1.20 through 26.3.

Choose the Fabric or Forge JAR from [GitHub Releases](https://github.com/xm4sters/PackGuard/releases).
